# Animal Species Prediction

Scalable architecture scaffold for an Animal Species Prediction platform.

Current scope:
- React + Vite + TailwindCSS app under `src/app`.
- NestJS API layer under `src/server`.
- FastAPI and TensorFlow worker scaffold under `worker`.
- Placeholder Supabase, auth, prediction, and model integration boundaries.

Not implemented yet:
- Supabase
- Google OAuth
- Authentication logic
- TensorFlow inference
- FastAPI endpoints
- Database logic
